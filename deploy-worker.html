🚀 Deploy KIUMA Stream Worker

⚡ Quick Deploy: Follow these 6 simple steps to enable real WebRTC streaming!

Step 1: Open Cloudflare Workers

Click this link: https://dash.cloudflare.com/workers

Login with your existing KIUMA account

Step 2: Create Worker

Click the big "Create Worker" button

Enter name: kiuma-stream-worker

Click "Deploy"

Step 3: Edit Code

Click "Edit code" button

Delete all existing code

Copy the entire content from: cloudflare-stream-worker.js

Paste it into the editor

Click "Save and Deploy"

Step 4: Add Route

Click "Add route" button

Enter route: kiuma-storage-kiuma4.kiuma4.workers.dev/*

Zone: Select your kiuma4 domain

Click "Save"

Step 5: Test Worker

Click on your worker name

Click "Preview" tab

Send test request to verify it's working

Step 6: Test Streaming

Go to your admin panel

Click "Start Streaming"

Watch console for WebRTC connection logs!

✅ Success!

Once deployed, you'll have real WebRTC streaming using your existing KIUMA infrastructure!

The worker handles WebRTC signaling and stream management automatically.

🔧 What the Worker Does:
  • Handles WebRTC signaling between admin and viewers
  • Manages stream creation and metadata
  • Provides fallback to simulation mode
  • Works with your existing Cloudflare account
