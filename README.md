# KIUMA App

**Kampala International University Muslim Association** — Official app for the Muslim community at KIU.

KIUMA is the Islamic body at Kampala International University (KIU) that promotes unity, dawah, education, welfare, and fellowship among Muslims. This app brings programs, events, prayer times, media, donations, and more into one place.

---

## Features

| Feature | Description |
|--------|-------------|
| **Prayer times** | Campus prayer times (Adhan & Iqaama), Hijri date, next prayer highlight |
| **Programs & events** | Programs, activities, and upcoming events; admin-managed |
| **Media & library** | Lectures, videos, and library resources |
| **Dhikr & 99 Names** | Dhikr counter and the 99 Names of Allah |
| **Quran** | Quran reader |
| **Donations** | Pay dues, donate to causes (e.g. tuition, charity) |
| **Join & engage** | Join programs, ask questions, counselling, leadership info |
| **Notifications** | Push notifications (when enabled) |
| **Offline** | Works offline where possible (PWA + service worker) |

---

## How to run

- **Web:** Open `index.html` in a browser, or serve the folder with any static server (e.g. `npx serve .`).
- **Android:** Build with [Capacitor](https://capacitorjs.com/) from this folder (`npx cap add android`, then build/sync and open in Android Studio).

---

## Tech

- Plain HTML/CSS/JS frontend
- Firebase (Auth, Firestore, optional Messaging)
- PWA (manifest, service worker, installable)
- Capacitor for Android (optional)
